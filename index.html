    Как пользоваться

    • Поиск работает сразу по обоим разделам: по тексту, региону или номеру инцидента. Можно ввести несколько слов, тогда найдутся записи, где есть все слова. Клавиша / переводит курсор в поиск, Esc очищает его.
    • Регионы. При выборе региона показываются его договорённости, договорённости для всех регионов и общие правила из раздела «Поля», где регион упомянут.
    • Отметка Новое стоит у записей, внесённых за последние 14 дней.
    • Номер инцидента в тексте копируется по клику.
    • 🔗 копирует ссылку на запись, ⧉ копирует её текст. Адрес страницы запоминает выбранный регион и поиск, так что им можно поделиться.

    Как обновить данные

    1. Внесите изменения в Excel-файл «Свод договоренностей.xlsx» (листы «Поля» и «Регионы»).
    2. Откройте репозиторий на GitHub → Add file → Upload files.
    3. Перетащите файл. Имя должно быть точно Свод договоренностей.xlsx, тогда GitHub заменит старую версию.
    4. Нажмите Commit changes. Сайт обновится через 1–2 минуты.

    Чтобы заранее посмотреть, как файл будет выглядеть на сайте, нажмите внизу страницы «Проверить новый файл перед загрузкой».
