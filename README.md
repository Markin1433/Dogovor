# Свод договорённостей

Внутренний справочник отдела: общие правила проверки инцидентов (раздел «Поля») и исключения по регионам (раздел «Регионы»).

Сайт: https://markin1433.github.io/Dogovor/

Сайт сам читает Excel-файл **`Свод договоренностей.xlsx`** из этого репозитория, поэтому для обновления данных достаточно заменить этот файл. Код править не нужно.

## Как добавить информацию

### Раздел 1 — «Поля» (лист «Поля» в Excel)

- Каждый столбец листа — отдельный блок на сайте («Группа тем/тема», «Итог», «Объект/Адрес» и т. д.).
- Чтобы добавить правило, впишите его в первую пустую ячейку под нужным столбцом.
- Чтобы добавить новый блок, впишите заголовок в первую строку свободного столбца, а правила ниже. На сайте появится новый блок.
- Перенос строки внутри ячейки (Alt+Enter) сохраняется на сайте.

### Раздел 2 — «Регионы» (лист «Регионы» в Excel)

Новую договорённость добавляйте строкой в конец таблицы:

| Дата внесения договоренности | Регион | Особенность |
|---|---|---|
| 08.10.2026 | Приморский край | Текст договорённости… |

- **Дата** — в формате даты Excel (например, `08.10.2026`). По ней работают сортировка и отметка «Новое» (последние 14 дней).
- **Регион** пишите так же, как в предыдущих строках, чтобы записи попадали в один регион. Регистр и лишние пробелы не важны: «ПРИМОРСКИЙ КРАЙ» и «Приморский край » считаются одним регионом.
- Для договорённостей, которые действуют везде, укажите регион **«ВСЕ РЕГИОНЫ»**.
- Ссылки (https://…) на сайте становятся кликабельными, номера инцидентов (5–8 цифр) копируются по клику.

### Загрузка файла на GitHub

1. Откройте https://github.com/Markin1433/Dogovor.
2. Нажмите **Add file → Upload files**.
3. Перетащите файл. Он должен называться точно **`Свод договоренностей.xlsx`**, тогда GitHub заменит старую версию. Если имя другое (например, `Свод договоренностей (1).xlsx`), сначала переименуйте файл.
4. Нажмите зелёную кнопку **Commit changes**.
5. Через 1–2 минуты обновите сайт (Ctrl+F5).

Проверить файл до загрузки можно на самом сайте: внизу страницы есть ссылка «Проверить новый файл перед загрузкой». Сайт покажет, как будут выглядеть новые данные, и предупредит о проблемах (например, о неверном имени файла). Эти данные видите только вы.

## Возможности сайта

- Один поиск по обоим разделам: по тексту, региону, дате или номеру инцидента. Несколько слов ищутся вместе. Клавиша `/` переводит курсор в поиск, `Esc` очищает его.
- В «Регионах» есть список регионов с количеством записей. При выборе региона показываются его договорённости, договорённости «для всех регионов» и упоминания региона в общих правилах.
- Сортировка: сначала новые или сначала старые. Записи за последние 14 дней отмечены «Новое».
- Можно скопировать текст записи или ссылку на неё. Адрес страницы запоминает выбранный регион и поиск, так что им удобно делиться.
- Сайт подстраивается под телефон и тёмную тему, страницу можно распечатать.

## Устройство

| Файл | Назначение |
|---|---|
| `Свод договоренностей.xlsx` | данные (единственное, что нужно обновлять) |
| `index.html` | разметка страницы |
| `style.css` | оформление |
| `app.js` | логика. Настройки (имя файла, срок «новых», написания регионов) в начале файла, в блоке `CONFIG` |
| `vendor/xlsx.mini.min.js` | библиотека SheetJS для чтения Excel (лежит в репозитории, интернет-CDN не нужен) |

Хостинг — GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**. Сервер арендовать не нужно.

Локальный просмотр: `python3 -m http.server` в папке репозитория, затем откройте http://localhost:8000. Если открыть `index.html` двойным кликом, браузер не даст прочитать Excel-файл, и сайт предложит выбрать его вручную.
